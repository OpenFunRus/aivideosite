Гайд по MiniMax H3: FL2VA, Ref2VA, Guides и ControlNet

Инструкция именно для нашего AI Video Studio: точные кадры, Characters, изображения, видео, голоса, timeline guides, ControlNet Union, editing/continuation и нативный H3 Audio.

Сначала выберите правильный режим

У H3 теперь четыре способа управлять сценой — плюс ControlNet поверх них.

FL2VA фиксирует точные endpoints. Ref2VA задаёт identity/style/motion/audio references. «Таймлайн» привязывает exact guide images к произвольным кадрам через native Add Guide. Fun ControlNet Union отдельно управляет структурой движения/геометрией или маской inpainting.

FLКадры: T2V, First, Last, First → Last
R2VРеференсы: до 9 pictures, 3 videos, 3 audio
TТаймлайн: до 16 exact Add Guide images по секундам
CNControlNet: Pose / Depth / Canny / HED / MLSD / inpaint
@Characters: постоянные внешность + optional voice
DHDigital Human: visual reference + ровно 1 driving audio
15Общий бюджет semantic Ref2VA: максимум 15 media resources
×32Выходные размеры сайта всегда на H3-валидной сетке
Важно про «keyframes»: обычная роль Storyboard/Keyframe в Ref2VA остаётся semantic reference и не фиксирует секунду. Для точной привязки используйте «Таймлайн»: native MiniMaxH3AddGuide записывает guide в конкретный frame_idx. FL2VA First/Last остаются самым простым способом точно закрепить только начало/конец.
01

Режим «Кадры» · FL2VA

Используйте его, когда важна точная стартовая или финальная композиция. Без картинок это обычный T2V. Один загруженный First — I2V. Один Last автоматически становится последним кадром. Два — интерполяция First → Last.

FL2VA — базовая структура 
integrated_multimodal_description: [Shot 1] Live-action, cinematic, [shot size], [subject + place + exact starting state]. The camera [one clear behavior]. [Actions in strict chronological order]. [Synchronized sounds/dialogue].

overall_soundscape: [Continuous ambience].

non_diegetic_music: [Audience-only score, or N/A].

Первый кадр

For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

Не переописывайте лицо и композицию как будто картинки нет. Считайте её точным состоянием в 0.00 и опишите первое видимое движение.

Последний кадр

Если загружен только Last, сайт сам отправляет его H3 как last keyframe. В prompt опишите, как действие естественно приходит к финальной позе и композиции.

First + Last

Интерполяция 10 секунд 
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 1) aligns with the 10.00-second mark of the target video.

integrated_multimodal_description: [Shot 1] In one continuous shot with no cuts, the video begins exactly from Picture 1. [Describe the continuous physical path]. During the final seconds, the subject, props and camera progressively settle into the pose, spacing and composition established by Picture 2.

overall_soundscape: [Ambience and synchronized physical sounds].

non_diegetic_music: N/A
02

Режим «Референсы» · Ref2VA

Ref2VA предназначен для сохранения личности/объекта/стиля, переноса движения, использования видео и голоса, редактирования или продолжения видео. В одной задаче сайт разрешает максимум 9 изображений, 3 reference videos, 3 standalone audio и 15 media всего. Нужен хотя бы один visual reference.

<Picture N>

Внешность, одежда, объект, локация, композиция, стиль, storyboard.

<Video N>

Действие, походка, танец, камера, исходное видео для edit/continue.

<Audio N>

Голос, тембр, ритм; soundtrack reference-video также получает Audio-номер.

Если вы вводите обычное описание сцены, сайт сам превращает его в расширенный шестипольный Ref2VA prompt. Если вы уже дали все шесть полей, сайт не переписывает ваш текст.

Полный Ref2VA-формат 
subject_definitions:
- <Subject 1>: the main character defined by <Picture 1> and <Picture 2>.
- <Video 1>: motion and camera reference.

summary: [reference generation / keyframe completion / video editing / video continuation / audio reuse / audio reference] One concise target-video summary.

retention_analysis:
- <Picture 1>: fully_preserved; role=character.
- <Video 1>: partially_preserved; role=motion.

detailed_description: [Shot 1] [Precise visual action, camera, timing, dialogue and exclusions].

overall_soundscape: [Ambience + requested scene audio].

non_diegetic_music: N/A
Нумерация сайта: Character images идут первыми среди Pictures, затем ваши загруженные images. Videos нумеруются отдельно. Soundtrack каждого reference-video получает Audio-номер перед standalone audio/Character voice. Для обычного prompt сайт собирает это автоматически — вручную считать номера не нужно.
03

Timeline Guides · точные кадры внутри ролика

Режим «Таймлайн» использует native ComfyUI MiniMaxH3AddGuide. Каждый загруженный still получает время в секундах; сайт переводит его в frame_idx = round(seconds × FPS) и цепочкой добавляет в conditioning перед sampler.

  • Можно поставить до 16 guide images в одной задаче.
  • Guide на 0.00 сек фиксирует внутренний первый кадр так же явно по таймлайну, но workflow остаётся Ref2VA-based.
  • Guide в середине — настоящий временной anchor, а не просто Picture со словом “storyboard”.
  • Guide near end должен физически быть достижим из предыдущего состояния — H3 всё равно генерирует движение между anchors.
  • Можно одновременно выбрать Characters/Ref2VA media: semantic refs отвечают за identity/style/motion, timeline guides — за конкретные визуальные состояния в конкретное время.
Версия: native Add Guide появился в ComfyUI 0.34+. Если backend старее, ComfyUI отвергнет workflow — обновите ComfyUI вместо добавления стороннего костыля.
Как писать prompt под guides
[Shot 1] In one continuous shot, begin in the state established by the 0.00s guide. Between 0.00s and 3.50s, [physical transition]. Around 3.50s, converge naturally into the exact guided composition. Continue from that state toward the 7.00s guide without a jump cut or teleport.
04

H3 Fun ControlNet Union

ControlNet работает поверх выбранного H3 mode и патчит transformer перед sampling. Наш сайт использует native ModelPatchLoader + MiniMaxH3FunControlNetApply.

CCanny Auto: raw video → built-in Canny → Union.
PPose: загрузите заранее подготовленный pose control video.
DDepth: заранее подготовленный depth video.
HHED: заранее подготовленный HED/soft-edge video.
MMLSD: заранее подготовленный line/geometry video.
IInpaint: source video + mask video; белое = regenerate.

Для Pose/Depth/HED/MLSD модель Union уже понимает соответствующий control representation, но сам preprocessor — отдельная задача. Поэтому сайт не притворяется, что RGB-video автоматически является Pose/Depth: для этих режимов нужен готовый control video. Canny — исключение, потому что Canny node встроен в ComfyUI и строится автоматически.

  • Strength: обычно начните с 1.0; слишком высокий может подавить prompt/references.
  • Start / End: доля sampling процесса от 0 до 1, где ControlNet активен.
  • Inpaint mask: mask video должно совпадать по времени/геометрии с source video; красный канал используется как MASK, белая область регенерируется.
  • ControlNet не заменяет Character/Ref2VA: он лучше удерживает структуру/движение, а refs — identity/style.
Версия и модель: Fun ControlNet Union требует ComfyUI 0.35+ и отдельный model patch minimax_h3_fun_controlnet_union_pruned_int8_convrot.safetensors в models/model_patches. Union 2.0 требует более новый ComfyUI (0.38+); текущий default сайта намеренно использует совместимый v1 patch.
05

Characters · постоянный персонаж

Вкладка «Персонажи» — наш локальный аналог удобства Mage @character, но без зависимости от Mage. У каждого из трёх пользователей своя изолированная библиотека.

  • Сохраните 1–4 reference images одного персонажа: лицо/голова, полный рост, одежда, характерные детали.
  • В поле «Неизменяемые особенности» фиксируйте то, что не должно случайно меняться между сценами: цвет/рисунок шерсти, причёска, одежда, обувь, аксессуары, телосложение.
  • При необходимости добавьте один voice reference. Он автоматически входит в Audio-бюджет Ref2VA.
  • В генераторе можно выбрать несколько Characters, пока суммарные media не превышают лимиты H3.
  • Удалить Character нельзя, пока активная задача использует его reference-файлы.
Лучше

Несколько чистых ракурсов одного и того же дизайна + короткое описание постоянных признаков.

Хуже

Коллажи с разной одеждой, возрастом, стилем и взаимоисключающими деталями.

06

Роль референса и retention

Для каждого загруженного reference сайт позволяет указать, что именно брать и насколько жёстко это сохранять. Это уменьшает конфликт между несколькими источниками.

Visual retention

100%fully_preserved — максимально удерживать identity/вид.
≈partially_preserved — сохранить основу, разрешить адаптацию.
→attribute_transfer — взять конкретный признак, а не весь source.
~weak_reference — лишь мягкий ориентир.

Audio retention

1:1fully_copy — максимально копировать аудио-свойства.
≈partially_copy — близко, но с адаптацией.
Rreference — голос/тембр/ритм как ориентир.
~weak_reference — слабое влияние.

Роли

character, object, setting, style, composition, storyboard, motion, camera_motion, voice, audio.

Если Picture нужен только как цвет/одежда, не помечайте его одновременно как максимально сохраняемый полный character — это создаёт лишний конфликт с главным reference.

07

Reference video, editing и continuation

Видео-референс позволяет передавать не только внешний вид кадра, но и динамику. В селекторе «Задача референсов» выбирайте намерение — сайт добавит его в summary.

  • Reference generation: использовать видео как motion/camera/behavior reference.
  • Video editing: изменить исходное видео: одежду, объект, окружение, стиль или отдельное действие, сохраняя нужную структуру source.
  • Video continuation: естественно продолжить действие и направление движения из reference video.
  • Storyboard / keyframe completion: связать несколько Picture-ориентиров. Это reference guidance, а не точный FL2VA таймлайн.
  • Audio reuse / reference: использовать soundtrack/voice как источник звукового поведения.
Soundtrack reference-video: если в загруженном видео есть аудиодорожка, локальный H3 Easy передаёт её вместе с Video reference автоматически. Она занимает Audio-номер модели, но не отдельный слот standalone audio в UI.
08

Digital Human

Используйте для персонажа, который должен следовать driving audio. В этом режиме нужны: минимум один visual reference (Picture/Video/Character) и ровно один standalone Audio driver.

  • Не выбирайте Character с сохранённым voice одновременно с отдельным driving audio: это даст два standalone Audio и сайт остановит отправку.
  • Driving audio задаёт речевую/вокальную временную структуру. В prompt описывайте внешний вид, кадр, поведение, эмоцию, камеру и окружение.
  • Если нужен слышимый результат H3 — оставьте «Генерировать со звуком» включённым.

10

Диалог, звук и музыка

Говорящим героям назначайте стабильные ID (S1), (S2). Точную фразу помещайте в <d> и не переводите, если пользователь не просил.

Русская реплика 
A woman (S1), speaking on-screen in a calm medium-pitched voice, looks at the camera and says: <d>[Russian] Я люблю Котика.</d>
  • Удар, дверь, смех в конкретный момент — рядом с действием в description.
  • Постоянная атмосфера — overall_soundscape.
  • Музыка, которую слышат персонажи (радио/телефон), — часть сцены.
  • Музыка только для зрителя — non_diegetic_music; если не нужна, N/A.
  • Отдельного negative prompt в нашем UI нет: пишите конкретные запреты прямо в description.
H3 Audio: аудио-инструкции могут участвовать в conditioning, но чтобы аудиодорожка попала в итоговый MP4, включите «Генерировать со звуком».

Примеры новых режимов

Ref2VA · Character + motion video 
subject_definitions:
- <Subject 1>: the main character, fully defined by <Picture 1> and <Picture 2>.
- <Video 1>: motion reference only.

summary: [reference generation] The main character performs the body motion from Video 1 while preserving the exact identity and outfit from Pictures 1–2.

retention_analysis:
- <Picture 1>: fully_preserved; role=character.
- <Picture 2>: fully_preserved; role=character.
- <Video 1>: partially_preserved; role=motion.

detailed_description: [Shot 1] In one continuous medium-full shot, Subject 1 keeps both feet planted and reproduces the torso and right-arm rhythm from Video 1. Preserve the face, body proportions, outfit and accessories from the Pictures. The camera remains at the same height and slowly pushes in. No extra people, subtitles, logos or watermarks.

overall_soundscape: Quiet room tone, light clothing rustle and natural breathing.

non_diegetic_music: N/A
Video continuation 
subject_definitions:
- <Video 1>: source video whose subjects, environment, movement direction and camera language define the continuation.

summary: [video continuation] Continue naturally from the end state of Video 1 without a visible reset.

retention_analysis:
- <Video 1>: fully_preserved; role=motion.

detailed_description: [Shot 1] The target begins as a seamless continuation of the final visible state in Video 1. Preserve the same subject identity, clothing, environment, lighting direction and camera height. Continue the existing movement with matching speed and momentum, then let the subject slow down, glance over the right shoulder and stop near the doorway. No jump cut, no sudden camera teleport, no new people.

overall_soundscape: Continue the environmental ambience and physical sound character naturally from the source.

non_diegetic_music: N/A

Ссылка для нейронки
Copy-paste для ChatGPT Короткая инструкция; полный справочник доступен кнопкой выше. 
Ты пишешь production-ready prompts для MiniMax H3 в моём локальном AI Video Studio.

Сайт имеет четыре режима:
1. Кадры / FL2VA: T2V, точный First frame, точный Last frame, First+Last.
2. Референсы / Ref2VA: до 9 Picture, 3 Video, 3 standalone Audio, 15 media всего; Characters считаются в эти лимиты.
3. Таймлайн / Multiframe Guide: Ref2VA + native MiniMaxH3AddGuide; до 16 exact guide images с точным временем.
4. Digital Human: минимум один visual reference и ровно один driving Audio.

Дополнительно поверх генерации может быть включён H3 Fun ControlNet Union:
- Canny Auto из raw video;
- prepared Canny / Pose / Depth / HED / MLSD control video;
- video inpainting через source video + mask video.

FL2VA:
- Используй поля integrated_multimodal_description, overall_soundscape, non_diegetic_music.
- First/Last — точные anchors. При First+Last описывай физический путь между картинками.

Ref2VA:
- Используй шесть полей: subject_definitions, summary, retention_analysis, detailed_description, overall_soundscape, non_diegetic_music.
- Ссылки: <Subject N>, <Picture N>, <Video N>, <Audio N>.
- Visual retention: fully_preserved / partially_preserved / attribute_transfer / weak_reference.
- Audio retention: fully_copy / partially_copy / reference / weak_reference.
- Задачи: reference generation, keyframe completion, video editing, video continuation, audio reuse, audio reference.
- Storyboard/keyframe Picture в обычном Ref2VA — только визуальный ориентир.
- Если выбран «Таймлайн», guide image ЯВЛЯЕТСЯ точным frame_idx anchor; prompt должен описывать физический переход между guide-times.
- Character — сохранённый reusable subject: внешность и иногда voice. Не придумывай другой дизайн, если Character выбран.
- Video reference может задавать motion, camera motion, behavior или исходник для edit/continuation.
- Soundtrack reference-video может стать Audio reference автоматически.

Timeline Guides:
- Учитывай точные времена каждого guide image.
- Не переописывай guided still как случайный reference: это временной anchor.
- Между anchors описывай непрерывный физически достижимый переход без teleport/jump, если пользователь не просил cut.

ControlNet:
- Canny/Pose/Depth/HED/MLSD задают структуру и motion, но не заменяют identity refs.
- Для inpaint сохраняй область вне белой mask, а изменения описывай для маскированной области.
- Если control слишком жёсткий, не обещай, что prompt полностью победит структуру source.

Общее:
- Пиши наблюдаемые действия в строгой хронологии.
- [Shot 1] без timestamp; следующий Shot: [Shot 2] At 00:04.000, the camera cuts to...
- Для одного дубля: one continuous shot with no cuts.
- Не перегружай камеру несколькими сложными движениями.
- Реплики сохраняй дословно на языке пользователя: <d>[Russian] ...</d>.
