Инструкция

Здесь собрана логика самого сайта и практические правила MiniMax H3. Ниже есть готовая полная инструкция для ChatGPT — одной кнопкой копируется V2-контекст вместе с актуальным H3 machine guide.

01

Создать

Обычная генерация: напишите сцену, при необходимости выберите персонажей и добавьте начальный/конечный кадр. Качество, формат, длительность и шаги выбираются только кнопками.

02

Продолжить

Для продолжения используется предыдущий ролик. V2 должен сам прочитать его формат и продолжить движение, камеру, направление и состояние сцены без ручной настройки размеров.

03

По аудио

Режим для клипов: загружается трек, выбирается герой/визуальный референс и описывается действие — танец, исполнение, мимика, движение ртом и камера.

04

Персонажи

Персонажи выбираются по имени через поиск. На основном экране остаются только выбранные. Список может содержать десятки героев; лимиты конкретной H3-задачи проверяются отдельно.

Как пользоваться волшебной палочкой

Пишите человеческим языком — не пытайтесь самостоятельно воспроизводить внутренний формат H3.

До

«Лиса сначала машет рукой, потом хитро улыбается, камера медленно приближается. 10 секунд.»

После

Локальный ИИ превращает запрос в структурированный английский H3 prompt, сохраняет точные русские реплики и учитывает выбранные медиа/персонажей.

MiniMax H3 — главное без перегруза

V2 скрывает большую часть терминологии, но эти принципы полезно знать.

Пишите действия по порядку.Что герой делает сначала, что затем и в каком состоянии заканчивает сцену.
Камера — конкретно.Один главный тип движения на кадр: static, push in, tracking, pan и т.п.
Начальный/конечный кадр.Это точные визуальные опорные состояния FL2VA, а не просто «похожие картинки».
Персонажи и референсы.Нужны для идентичности, внешности, одежды, голоса и других сохраняемых признаков.
Продолжение видео.Важно сохранять направление движения, позу, скорость, камеру, освещение и географию сцены.
Звук.Диалог, шум действия, постоянная атмосфера и музыка — разные слои. Для слышимого native H3 audio должен быть включён звук.
Точные реплики.Русский текст реплик остаётся русским; техническая часть production prompt пишется на английском.
Не перегружайте.Лучше короткая физически выполнимая сцена, чем десяток действий и движений камеры за 5 секунд.
