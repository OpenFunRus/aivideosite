1. THE SINGLE BIGGEST HACK: STRUCTURE BEATS ADJECTIVES
===============================================================================

[OFFICIAL + STRONG HEURISTIC]

H3 responds much better to its trained prompt structure than to a large free-form
cinematic paragraph.

Bad optimization:
- more adjectives;
- "masterpiece, stunning, cinematic, ultra detailed";
- random camera jargon;
- repeated identity text;
- huge negative lists.

Better optimization:
- correct mode;
- correct field order;
- clear shot chronology;
- stable speaker IDs;
- clear reference roles;
- concrete camera movement;
- explicit final state;
- clean sound separation.

Community reports repeatedly describe gibberish dialogue, wrong speakers, random cuts,
and ignored instructions improving dramatically once the official base/ref syntax is used.

===============================================================================
2. START SIMPLE, THEN ADD ONE CONTROL AXIS AT A TIME
===============================================================================

[STRONG HEURISTIC]

For a difficult scene, prototype in layers:

Pass A:
- one subject;
- one location;
- one action;
- static or slow camera;
- no dialogue.

Pass B:
- add the required dialogue or sound.

Pass C:
- add camera movement.

Pass D:
- add secondary character interaction.

Pass E:
- add exact last-frame landing, extra reference, or complex lighting only if needed.

This isolates failure causes. If identity breaks after adding a fast arc shot, you know
the camera/motion load caused the regression rather than the Character reference itself.

Change one major variable per revision whenever practical.

===============================================================================
3. DURATION IS A BUDGET, NOT A LABEL
===============================================================================

[OFFICIAL + STRONG HEURISTIC]

A 5-second video is not a 15-second screenplay rendered faster.

Dialogue timing:
- Natural Russian/English speech varies with delivery.
- Do not squeeze a long sentence plus gestures plus a camera reveal into 5 seconds.
- If a line must be exact, make other action simpler.

Action timing:
- entrance + approach + object pickup + conversation + exit is too much for a short clip.
- Choose the one beat that matters.

If the written action finishes early, H3 may pad with:
- idle drift;
- extra mouth movement;
- extra speech-like gibberish;
- unnecessary camera motion;
- repeated gestures.

If the written action is too long, H3 may:
- skip beats;
- compress dialogue;
- overlap speakers;
- teleport objects;
- miss the final frame.

===============================================================================
4. MULTI-CHARACTER DIALOGUE RELIABILITY
===============================================================================

[OFFICIAL + COMMUNITY]

For two or more speakers:
- define each speaker clearly;
- assign stable S1/S2 IDs in actual speaking order;
- put each line beside that person's action;
- state "S2 remains silent" when only S1 should speak;
- avoid simultaneous camera chaos during critical dialogue;
- avoid giving both characters similar unnamed voice descriptions;
- if using voice references, use one voice reference per intended speaker when possible.

If H3 starts with gibberish before the real line:
- reduce silent lead-in time;
- start with a visible preparatory action;
- make overall_soundscape explicit;
- state that no one speaks before S1's exact line;
- ensure there is enough real dialogue/action to occupy the timeline without inventing filler.

If speakers overlap:
- state "S2 waits until S1 finishes completely";
- tie the second line to a visible event that occurs after the first finishes;
- reduce the number of independent actions happening during speech.

===============================================================================
5. RUSSIAN DIALOGUE
===============================================================================

[OFFICIAL + PRACTICAL]

Use exact Russian words inside:
<d>[Russian] ...</d>

Keep the rest of the production prompt in English.

Pronunciation fixes:
- prefer ordinary punctuation;
- avoid excessive ellipses;
- avoid creative spellings unless the desired pronunciation truly needs them;
- if one word is mis-stressed consistently, rewrite the sentence around that word
  rather than adding phonetic clutter everywhere;
- do not mix Italian/English/Russian instructions in the spoken-content tag;
- do not put stage directions inside <d>.

A reliable pattern:
The adult woman with a warm calm voice (S1) looks at him and says:
<d>[Russian] Не переживай, милый.</d>

Stage direction remains outside the tag.

===============================================================================
6. IDENTITY LOCK: WHAT ACTUALLY HELPS
===============================================================================

[OFFICIAL + STRONG HEURISTIC]

Best ingredients:
- 2–4 consistent reference images of the same exact look;
- useful angle diversity;
- no contradictory wardrobe/hair/age references;
- concise text description of immutable features;
- moderate camera motion;
- reasonable pose changes;
- no unnecessary transformation.

Identity failure often rises when all of these happen at once:
- face turns fully away;
- fast orbit camera;
- strong body motion;
- complex hand interaction;
- another similar-looking person;
- dark/occluded lighting;
- wardrobe change;
- expression change;
- low reference strength / turbo path.

When identity matters more than spectacle:
- simplify motion first;
- keep face visible at important moments;
- avoid extreme perspective distortion;
- use a continuous shot;
- let the Character references do identity work instead of repeating a novel-length face description.

===============================================================================
7. LOCATION CONSISTENCY
===============================================================================

[STRONG HEURISTIC]

Treat a location like a character:
- stable architecture;
- stable furniture;
- stable materials;
- stable window/door positions;
- stable light source;
- stable weather/time of day;
- stable damage/decay state.

When using several location images:
- say they are multiple views of the same place;
- do not describe mutually incompatible layouts;
- do not select three different Location presets unless the scene transitions between them.

For interior continuity:
- mention where the camera is relative to the main anchor (door, table, window, stove);
- preserve left/right relationships when the next clip starts from a final frame.

===============================================================================
8. FIRST-FRAME CONTINUATION
===============================================================================

[STRONG HEURISTIC FOR THIS SITE]

The removed "Continue" workspace is intentionally replaced by a more controllable method:

1. Export the previous video's final PNG frame from Library.
2. Put it into Create -> First Frame.
3. Re-select the same Characters/Location presets.
4. Keep the same aspect ratio and quality unless a change is intentional.
5. Write only the next action.
6. State continuity where H3 can otherwise reinterpret:
   - same person;
   - same clothing;
   - same held objects;
   - same location;
   - same lighting/time of day;
   - same screen direction;
   - same camera height and orientation.
7. Start motion from the exact visible pose rather than re-describing an earlier state.

For a seamless cut, avoid a large camera jump in the first few frames of the new clip.

===============================================================================
9. FIRST + LAST FRAME RELIABILITY
===============================================================================

[OFFICIAL + STRONG HEURISTIC]

To improve endpoint landing:
- make start and end compositions compatible;
- minimize unrelated location changes;
- describe the physical interpolation;
- keep one continuous shot if possible;
- describe final body/prop/camera state explicitly;
- avoid adding a late event after the landing;
- if the last frame differs radically, give the model enough time.

If the output ignores the last frame:
- reduce intermediate complexity;
- remove extra cuts;
- reduce camera motion;
- increase the proportion of prompt devoted to the transition path;
- verify both endpoint images use compatible dimensions/aspect ratios.

===============================================================================
10. CAMERA HACKS
===============================================================================

[OFFICIAL + COMMUNITY]

Specific camera language is better than vague "camera moves cinematically".

Good:
- "The camera pushes in with small amplitude at slow speed toward his face."

Weak:
- "The camera slowly moves closer."

For dialogue:
- static or slow push-in is often safer than large orbiting.

For action:
- tracking shot follows translation well.
- truck is useful for lateral reveal.
- pan rotates in place; truck translates the camera. Do not confuse them.
- zoom changes focal length; push-in moves the camera physically.

Avoid stacking three camera moves unless the shot truly needs them.

11. AUDIO AND UNWANTED MUSIC
===============================================================================

[OFFICIAL]

If no score:
non_diegetic_music: N/A

If no H3 ambience/sound:
overall_soundscape: N/A

Do not rely on "no music" hidden inside a huge visual paragraph.
Use the dedicated field.

For the site's Audio workspace:
- master track is external;
- non_diegetic_music is normally N/A;
- H3 background sounds should be N/A when the UI toggle is off;
- do not describe the external song as if H3 must compose it;
- do not invent missing lyrics.

===============================================================================
12. REFERENCE BUDGET STRATEGY
===============================================================================

[OFFICIAL + SITE-SPECIFIC]

Upstream official mixed-reference cap is 12 files.
Current local site validator still allows 15 total references, with:
- <= 9 images;
- <= 3 videos;
- <= 3 audio.

Treat 12 as the conservative H3 upstream budget even if the current site UI/backend
permits 13–15 total media. If quality/adherence is unstable, reduce references rather
than filling every slot.

Priority order for a character scene:
1. essential identity views;
2. essential location views;
3. voice reference if needed;
4. exact guide frames;
5. optional style/motion references last.

More references are not automatically better.

===============================================================================
13. TURBO VS BASE
===============================================================================

[OFFICIAL/COMFYUI + HEURISTIC]

Turbo/Lightning LoRAs are useful for iteration speed but may weaken:
- small identity details;
- reference adherence;
- audio quality;
- complex motion.

Practical workflow:
- validate composition/action fast;
- move to the more stable base/higher-step path for a final difficult shot;
- do not judge a complex character-reference failure solely from the fastest turbo run.

This V2 exposes 1/4/8/12/16 steps rather than the full raw ComfyUI space. Low-step runs use full VAE decoding but may have poor sound and imagery.
Respect the site's buttons; do not invent a 25-step UI value.

===============================================================================
14. PROMPT LENGTH
===============================================================================

[OFFICIAL + COMMUNITY INTERPRETATION]

Do not pad prompts to hit a word target.

A prompt is complete when it contains every necessary:
- subject;
- state;
- action;
- camera;
- timing;
- dialogue;
- sound;
- music;
- continuity constraint.

Dense scenes need more words. Simple scenes need fewer.
Redundant prose competes with the important constraints.

A useful editing pass:
- delete repeated adjectives;
- delete repeated identity descriptions;
- delete irrelevant backstory;
- keep physical facts;
- keep chronology;
- keep exact dialogue;
- keep reference roles;
- keep final state.

16. COMMON FAILURE -> FIX TABLE
===============================================================================

Failure: wrong person speaks
Fix:
- stable S IDs;
- line beside visible speaker;
- explicit silence for others;
- one voice ref per speaker where possible.

Failure: gibberish before/after dialogue
Fix:
- exact <d> structure;
- less empty timeline;
- state no speech outside the exact line;
- simplify actions.

Failure: random cut
Fix:
- one-shot wording;
- explicit static/tracking camera;
- remove vague "dynamic cinematic montage" language.

Failure: face changes
Fix:
- stronger cleaner references;
- fewer simultaneous transformations;
- calmer camera;
- better light;
- preserve wardrobe/hair/age explicitly.

Failure: location changes
Fix:
- one Location preset;
- lock architecture/layout/materials/light;
- avoid contradictory location refs.

Failure: prop switches hands/disappears
Fix:
- state initial hand;
- describe grasp path;
- state final hand/position;
- keep prop visible.

Failure: final frame missed
Fix:
- simplify path;
- remove cuts;
- explicitly converge on final geometry;
- ensure enough duration.

Failure: extra music
Fix:
- non_diegetic_music: N/A.

Failure: extra dialogue
Fix:
- exact lines only;
- explicit silence otherwise;
- fill runtime with visible nonverbal action instead of empty time.

Failure: master-track audio is re-created badly
Fix:
- non_diegetic_music: N/A;
- treat master track as external;
- only request H3 scene sounds if toggle is on.

Failure: too many references weaken adherence
Fix:
- remove nonessential refs;
- assign one clear role to each;
- prioritize identity/location/voice.

===============================================================================
17. REVISION DISCIPLINE
===============================================================================

When a generation is close:
- do not rewrite the entire prompt;
- identify the single failed dimension;
- patch only that dimension;
- preserve all successful details.

Examples:
- dialogue correct, camera bad -> only repair camera wording;
- identity correct, location drifts -> strengthen location constraints;
- endpoint correct, speech rushed -> shorten line or simplify action;
- motion correct, unwanted music -> set music field to N/A.

This makes iteration predictable and preserves successful latent behavior.

===============================================================================

The best "hack" is not a secret keyword.
It is:
correct mode + correct structure + concrete chronology + clean reference roles +
stable identity + explicit audio separation + realistic duration budget.

================================================================
MISC PRESET PRACTICAL PLAYBOOK
================================================================

Use Misc presets when a visual element must recur across clips without turning it into
a Character or Location.

Good examples:
- "Soviet cassette player" as prop, with clean front/side images;
- "red field jacket" as clothing_gear, focused on the garment rather than a whole scene;
- "diagonal scar over left eyebrow" as visual_trait;
- a specific old car as vehicle with multiple useful angles;
- a characteristic stance as pose_action;
- a lighting/graphic treatment as style_look.

Reliability rules:
1. Keep one preset semantically coherent. Do not mix unrelated objects in its 1–4 images.
2. Multiple angles of the same object are usually more useful than near-duplicate shots.
3. The description should state the invariant details worth preserving: form, materials,
   dominant colors, markings, wear, attachment/holding point, or intended transferable trait.
4. If the object must be held/used, say who interacts with it, in which hand/body position,
   and what it does. A reference alone does not fully specify scene interaction.
5. Clothing/gear refs should be applied to the intended Character without replacing that
   Character's face/body identity.
6. visual_trait should describe the local trait precisely; avoid asking H3 to transfer an
   entire unrelated face just to obtain one scar/tattoo/marking.
7. pose_action is a semantic cue, not guaranteed frame-perfect choreography. Use Timeline
   Guides or ControlNet when exact geometry/timing matters.
8. style_look is best treated as appearance/cinematography guidance; do not copy accidental
   subjects or props from the style reference.
9. Misc images consume the same image budget as Characters and Locations. Prefer the
   smallest useful set of clean references instead of spending all slots automatically.
10. When a selected Misc conflicts with an explicit current user request, do not silently
    force the preset into an unrelated role. Preserve the preset's identity while following
    the user's explicit scene intent.
