1. VIDEO WORKSPACE
===============================================================================

Purpose:
Create every MiniMax H3 video from one unified workspace.

Main inputs:
- text prompt;
- optional exact First Frame;
- optional exact Last Frame;
- Characters;
- Locations;
- Misc semantic references;
- optional master track enabled by "Использовать аудиодорожку"; it becomes H3 driving audio whenever any visual input exists (First/Last or a semantic visual preset).

Prompt:
- one textarea up to 16,000 characters;
- one inline Magic Wand;
- Magic Wand always returns the canonical H3 Video three-field prompt;
- it follows runtime generation_mode/has_driving_audio: audio_mode with no visual input is prompt-only FL2VA + optional mux; audio_mode with First/Last or semantic presets is Digital Human driving audio.

Frame inputs:
- First Frame;
- Last Frame;
- JPG/PNG/WEBP;
- preview/remove actions.

Visible shared settings:
- Quality: 480p / 720p / 1080p
- Format: 1:1 / 16:9 / 9:16
- Duration: 5 / 10 / 15 sec
- Steps: 8 / 12 / 16
- Seed

Normal Video mode:
- no semantic presets, no frames -> base video path;
- First and/or Last without semantic presets -> FL2VA exact endpoint conditioning;
- Characters/Locations/Misc -> Ref2VA semantic references;
- semantic presets + endpoint frames -> Ref2VA semantic references plus exact native Timeline Guides;
- "Генерировать звук" controls ordinary H3-generated audio.

Master-track mode:
- user enables "Использовать аудиодорожку";
- user selects a saved master track OR uploads one;
- waveform selects the start of the 5/10/15-second fragment;
- normal "Генерировать звук" is hidden in this mode;
- "Вклеить трек в видео" controls final mux of the original selected fragment;
- "Фоновые звуки H3" controls optional generated diegetic/foley scene sound.

Without any visual input (no First/Last and no Character/Location/Misc):
- the master track is NOT supplied to H3 as Digital Human driving audio;
- prompt-only generation uses the ordinary FL2VA/text-to-video path;
- the track may still be muxed into the final MP4.

With First/Last OR Character/Location/Misc:
- the selected fragment becomes the single Digital Human driving audio;
- preset images are semantic visual references when selected;
- otherwise the first available endpoint image (First preferred, otherwise Last) is reused as the required Digital Human visual reference;
- First Frame is additionally attached as an exact native MiniMaxH3AddGuide at 0 seconds;
- Last Frame is additionally attached as an exact native MiniMaxH3AddGuide at the selected duration;
- endpoint guide images are NOT Picture labels the Magic Wand should invent.

Prompt rules:
- runtime generation_mode and has_driving_audio are authoritative;
- if has_driving_audio=true, visible singing, articulation, gestures and body motion should synchronize to the supplied audio;
- if has_driving_audio=false, this is the prompt-only fallback with no visual input;
- with audio_mode=true: non_diegetic_music: N/A;
- if H3 background sound is OFF: overall_soundscape: N/A;
- if ON: overall_soundscape contains only additional physical/diegetic scene sound;
- never invent lyrics.

Manual continuation:
- Library -> export Final Frame PNG;
- Video -> load it as First Frame;
- select the same continuity presets;
- describe only the next action;
- driving audio may also be enabled for the next segment when needed.

===============================================================================
2. PRESETS — CHARACTERS
===============================================================================

Character preset:
- id;
- name;
- description;
- 1–4 appearance reference images;
- optional saved voice/custom voice/preset voice.

Character images are H3 Video identity references.
A built-in voice preset is a real configured voice reference.
Voice can be muted for ordinary video generation.

In driving-audio mode the selected master track is the single Digital Human audio driver;
Character appearance images still work as visual identity references.

When talking to the user, use human-readable names and metadata rather than IDs unless
the user explicitly asks for IDs.

===============================================================================
3. PRESETS — LOCATIONS
===============================================================================

Location preset:
- id;
- name;
- prompt;
- 1–4 environment reference images.

Use Location references for architecture, layout, materials, lighting and environmental
continuity. Multiple images are views of the same saved place.

7. LIBRARY GPU & ACTIVE JOBS
===============================================================================

Purpose:
Show both GPUs and active generation/export cards in Library. The Queue view is retired.

GPU lanes:
- RTX3090 primary H3 Video lane;
- RTX2080 secondary/overflow H3 Video lane.

Jobs:
- generation shows animated progress and actual elapsed time, with no intermediate images;
- select 8, 12 or 16 steps; every job produces final MP4 via full Video VAE and optional Audio VAE;
- changing the step count changes video and sound even with an identical seed; each run is separate;
- completed videos show start date and generation duration;
- queued/running jobs are preserved in the backend database.

13. MAGIC WAND CONTRACT
===============================================================================

Magic Wand exists only in Video.

It receives:
1. static H3 Video knowledge;
2. exact current unified Video settings (quality, resolved resolution, ratio, duration, FPS, steps, seed, H3 audio, endpoint mode, master-track state/range and audio toggles);
3. deep metadata only for currently checked Character/Location/Misc presets plus muted voice state;
4. the persistent user_prompt when configured;
5. user's ordinary-language request.

It returns only the final H3 Video prompt text:
- no JSON;
- no Markdown;
- no explanation.

Canonical fields in exact order:
1. integrated_multimodal_description
2. overall_soundscape
3. non_diegetic_music

When audio_mode=false:
- follow ordinary FL2VA/Ref2VA/Timeline rules;
- First/Last without semantic refs may require the normal FL2VA alignment line;
- First/Last with semantic refs are backend-owned exact Timeline Guides.

When audio_mode=true:
- runtime generation_mode/has_driving_audio are authoritative;
- with no visual input, generation_mode remains frames and the master track is not an H3 driving input;
- with First/Last or Character/Location/Misc visual input, generation_mode is Digital Human and the master track is the driving audio;
- First/Last in Digital Human mode are backend-owned exact native AddGuide anchors;
- never add FL2VA alignment for those frames;
- never invent Picture labels for those frames;
- non_diegetic_music: N/A;
- overall_soundscape is N/A unless additional scene sound is explicitly enabled.
