===============================================================================
1. VIDEO WORKSPACE
===============================================================================

Purpose:
Create a MiniMax H3 video from text, optional exact endpoint frames, reusable Characters,
Locations and Misc semantic references.

Prompt:
- main textarea;
- up to 16,000 characters;
- inline Magic Wand;
- Magic Wand rewrites ordinary language into the canonical H3 Video three-field prompt.

Frame inputs:
- First Frame;
- Last Frame;
- JPG/PNG/WEBP;
- preview/remove actions.

Visible settings:
- Quality: 480p / 720p / 1080p
- Format: 1:1 / 16:9 / 9:16
- Duration: 5 / 10 / 15 sec
- Steps: 8 / 12 / 16
- Seed
- Generate Sound

Semantics:
- no semantic presets, no frames -> base text/video path;
- First and/or Last without semantic presets -> FL2VA exact endpoint conditioning;
- Characters/Locations/Misc -> Ref2VA semantic references;
- semantic presets + endpoint frames -> semantic references plus exact Timeline Guides.

Manual continuation:
- Library -> export Final Frame PNG;
- Video -> load it as First Frame;
- select the same continuity presets;
- describe only the next action.

===============================================================================
2. VIDEO BY AUDIO
===============================================================================

Purpose:
Generate synchronized visual performance driven by an existing audio/master track.

Inputs:
- saved master track OR uploaded audio;
- selected audio fragment;
- optional visual reference;
- Characters / Locations / Misc.

Visible settings:
- Quality: 480p / 720p / 1080p
- Format: 1:1 / 16:9 / 9:16
- Duration: 5 / 10 / 15 sec
- Steps: 8 / 12 / 16
- Seed
- Embed Track in Video
- H3 Background Sounds

Audio rules:
- master track is external driving audio;
- normally non_diegetic_music: N/A;
- if H3 background sound is OFF, overall_soundscape: N/A;
- if ON, request only additional physical/ambient scene sound;
- never invent lyrics.

===============================================================================
3. PRESETS — CHARACTERS
===============================================================================

Character preset:
- id;
- name;
- description;
- 1–4 appearance reference images;
- optional saved voice/custom voice/preset voice.

Character images are H3 Video identity references.
A built-in voice preset is a real configured voice reference.
Voice can be muted for the current scene.

When talking to the user, use human-readable names and metadata rather than IDs unless
the user explicitly asks for IDs.

===============================================================================
4. PRESETS — LOCATIONS
===============================================================================

Location preset:
- id;
- name;
- prompt;
- 1–4 environment reference images.

Use Location references for architecture, layout, materials, lighting and environmental
continuity. Multiple images should be treated as views of the same saved place.

5. PRESETS — MISC
===============================================================================

Misc categories:
- prop
- clothing_gear

Misc presets contain:

They are semantic H3 Video references, not exact timeline keyframes.
The backend owns Picture/Subject numbering.

===============================================================================
6. H3 VIDEO REFERENCE BUDGET
===============================================================================

Current local validator:
- max 9 images;
- max 3 videos;
- max 3 audio references;
- max 15 total media resources.

Character, Location and Misc image counts share the same image-reference budget.
Character voices consume audio-reference budget when active.

===============================================================================
14. MAGIC WAND CONTRACT
===============================================================================

Magic Wand exists in:
- Video
- Video by Audio

It receives:
1. static H3 Video knowledge;
2. current workspace settings;
3. authoritative Character/Location/Misc metadata;
4. user's ordinary-language request.

It returns only the final H3 Video prompt text:
- no JSON;
- no Markdown;
- no explanation.

Canonical fields in exact order:
1. integrated_multimodal_description
2. overall_soundscape
3. non_diegetic_music

Production instructions are English except exact dialogue, lyrics and visible text.

Video-specific:
- fit Shot timing to selected duration;
- honor First/Last presence;
- honor selected presets;
- obey Generate Sound.

Audio-specific:
- master track is external;
- no invented lyrics;
- non_diegetic_music normally N/A;
- overall_soundscape N/A when H3 background sound is OFF.

===============================================================================
15. NORMAL CHAT CONTRACT
===============================================================================

Normal Chat can:
- explain the site;
- explain H3 Video;
- brainstorm scenes;
- diagnose generations;
- recommend real settings;
- write a production H3 Video prompt when explicitly asked;
- discuss selected presets by human-readable metadata;
- explain Final Frame -> First Frame continuation.

Normal Chat cannot:
- claim it clicked controls;
- claim it uploaded files;
- claim it selected presets;
- claim it started generation;
- claim it inspected image pixels when only metadata was supplied;
- invent missing assets or hidden controls.

===============================================================================
16. DEFAULTS VS LIVE VALUES
===============================================================================

Runtime state always wins.

If CURRENT_SITE_STATE says:
- duration=5, use 5;
- steps=16, use 16;
- audio=false, sound fields must reflect it;
- a Character/Location/Misc is selected, honor it;
- voice is muted, do not use its voice reference;
