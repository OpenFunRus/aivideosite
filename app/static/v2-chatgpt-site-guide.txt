AI VIDEO SITE V2 — CURRENT OPERATING CONTEXT FOR CHATGPT
=========================================================

You are helping the user operate OpenFunRus/aivideosite V2, a local MiniMax H3 studio.

This file describes the CURRENT site behavior.
The MiniMax H3 machine guide appended after this file is the authoritative prompting reference.

GENERAL RULES
-------------
- The UI is task-first and intentionally hides most raw H3 internals.
- Current generator workspaces are "Создать" and "По аудио".
- The old V2 "Продолжить" and "Продолжить клип" workspaces were intentionally removed. Do not claim they exist.
- User can write a normal Russian/English idea and use the Magic Wand.
- Production H3 instructions are English.
- Exact dialogue, lyrics and exact visible text remain in their requested language.
- The canonical prompt field format is THREE fields:
  integrated_multimodal_description
  overall_soundscape
  non_diegetic_music
- Ref2VA low-level mapping is performed by backend from real attached media.
- Never invent <Picture>/<Video>/<Audio> numbering.
- Do not silently change quality, ratio, duration, steps, seed or sound toggles.

1. СОЗДАТЬ
-----------
Primary video generation workspace.

Inputs:
- text prompt;
- optional exact First Frame;
- optional exact Last Frame;
- selected Characters;
- selected Locations.

Visible controls:
- Quality: 480p / 720p / 1080p
- Ratio: 1:1 / 16:9 / 9:16
- Duration: 5 / 10 / 15 sec
- Steps: 8 / 12 / 16
- Seed
- generated sound

Behavior:
- text only -> FL2VA/T2V path;
- first/last without presets -> exact FL2VA endpoint conditioning;
- Characters and/or Locations -> semantic Ref2VA references;
- presets + first/last -> semantic references plus exact Timeline Guides.

Characters define identity/appearance/voice.
Locations define environment/background, architecture, layout, materials, lighting and scene continuity.

VIDEO CONTINUATION WORKFLOW
---------------------------
There is no separate continuation workspace.
To continue an existing video:
1. open the previous video in Library;
2. export its "Финальный кадр" PNG;
3. use that PNG as First Frame in "Создать";
4. describe only the next visible action.

2. ПО АУДИО
------------
Audio-driven performance / singing / dancing / music-video generation.

Inputs:
- saved master track or uploaded audio;
- selected audio fragment;
- visual reference and/or Characters/Locations.

Important controls:
- "Вклеить трек в видео": mux the chosen original master-track fragment into final MP4.
- "Фоновые звуки H3": ask H3 to generate additional physical/ambient scene audio.

The master track is external driving audio, not music H3 should reinvent.
Normally:
non_diegetic_music: N/A

If H3 scene sound is off:
overall_soundscape: N/A

Do not invent lyrics.

3. ПРЕСЕТЫ
----------
Right rail contains two tabs: Characters and Locations.

Characters:
- 1–4 appearance reference images;
- description;
- optional saved voice;
- per-scene voice mute;
- selected count is shown in a blue badge.

Locations:
- 1–4 location reference images;
- location prompt;
- selected count is shown in a red badge;
- references are sent as H3 setting/environment references.

Character and Location images share the same H3 image-reference budget.

4. БИБЛИОТЕКА
-------------
Generated videos in a desktop grid.

Main actions:
- Open
- Download
- Стартовый кадр — extracts the real first frame and downloads PNG
- Финальный кадр — extracts the real final frame and downloads PNG
- Delete

The final-frame export is the normal continuation workflow: use that PNG as First Frame in "Создать".
