CURRENT GENERATOR WORKSPACE
---------------------------
There is ONE generator workspace: "Видео".

Separate "Видео по аудио", "Продолжить", "Продолжить клип", and "Изображения" pages do not exist.

The right Presets rail contains:
- Characters
- Locations

VIDEO
-----
Inputs:
- text prompt;
- optional exact First Frame;
- optional exact Last Frame;
- Characters;
- Locations;
- Misc semantic references;
- optional integrated driving master track.

Visible shared controls:
- Quality: 480p / 720p / 1080p
- Format: 1:1 / 16:9 / 9:16
- Duration: 5 / 10 / 15 sec
- Steps: 8 / 12 / 16
- Seed

NORMAL VIDEO MODE
-----------------
With "Использовать аудиодорожку" OFF:
- text only -> base video path;
- First/Last without presets -> exact FL2VA endpoints;
- Characters/Locations/Misc -> Ref2VA semantic references;
- presets + First/Last -> semantic refs + exact native Timeline Guides;
- normal "Генерировать звук" controls H3-generated audio.

DRIVING-AUDIO MODE INSIDE VIDEO
-------------------------------
Enable "Использовать аудиодорожку".

Then:
- select a saved master track OR upload one;
- move the waveform window to choose the fragment start;
- the 5/10/15-second fragment becomes the single Digital Human driving audio;
- there is NO separate arbitrary visual-reference upload;
- Characters/Locations/Misc remain semantic visual references;
- if no preset visual is selected, First Frame is reused as the required semantic visual;
  if First is absent, Last Frame is reused instead;
- First Frame is also an exact native MiniMaxH3AddGuide anchor at 0 seconds;
- Last Frame is also an exact native MiniMaxH3AddGuide anchor at the selected duration;
- endpoint images are backend-owned guides, not Picture labels for the prompt;
- "Вклеить трек в видео" controls final mux of the original fragment;
- "Фоновые звуки H3" controls optional extra diegetic/foley sound;
- the normal "Генерировать звук" option is hidden.

Prompt rules in driving-audio mode:
- master track is already supplied as driving audio;
- non_diegetic_music: N/A;
- overall_soundscape: N/A when H3 scene sound is OFF;
- when ON, request only physical/diegetic scene sound;
- never invent lyrics;
- synchronize visible mouth/body performance to the supplied audio;
- do not use FL2VA alignment for First/Last in this mode.

MAGIC WAND
----------
There is one Magic Wand in Video.

It always returns the canonical H3 Video three-field prompt:
1. integrated_multimodal_description
2. overall_soundscape
3. non_diegetic_music

It reads the current audio_mode and applies either normal Video rules or Digital Human rules.
Backend owns all real Picture/Video/Audio numbering.
