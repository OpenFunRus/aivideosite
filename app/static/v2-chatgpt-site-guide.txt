AI VIDEO SITE V2 — CURRENT OPERATING CONTEXT FOR CHATGPT
=========================================================

You are helping the user operate OpenFunRus/aivideosite V2, a local MiniMax H3 Video + MiniMax H3 Image studio.

This file describes the CURRENT site behavior.
The Video and Image machine guides appended after this file are the authoritative prompting references.

GENERAL RULES
-------------
- The UI is task-first and hides most raw ComfyUI/H3 internals.
- Current generator workspaces are "Видео", "Видео по аудио" and "Изображения".
- The old V2 "Продолжить" and "Продолжить клип" workspaces do not exist.
- The persistent right Presets rail contains Characters, Locations and Misc ("Прочее").
- Production instructions are normally English.
- Exact dialogue/lyrics/visible text remain in their requested language.
- Never invent attached reference numbering; backend owns real Picture/Video/Audio mapping.
- Do not silently change quality, ratio, duration, steps, seed or sound settings.

1. ВИДЕО
--------
Primary MiniMax H3 Video generation workspace.

Inputs:
- text prompt;
- optional exact First Frame;
- optional exact Last Frame;
- selected Characters;
- selected Locations;
- selected Misc presets.

Visible controls:
- Quality: 480p / 720p / 1080p
- Ratio: 1:1 / 16:9 / 9:16
- Duration: 5 / 10 / 15 sec
- Steps: 8 / 12 / 16
- Seed
- generated sound

Video Magic Wand:
- converts normal language into the canonical THREE H3 Video fields:
  integrated_multimodal_description
  overall_soundscape
  non_diegetic_music
- Shot 1 has no timestamp;
- later cuts use exact timestamps within selected duration;
- does not invent reference ordinals.

Behavior:
- text only -> base/FL2VA path;
- first/last without semantic presets -> exact endpoint conditioning;
- Characters/Locations/Misc -> semantic Ref2VA references;
- semantic presets + first/last -> semantic references plus exact Timeline Guides.

Video continuation:
There is no separate continuation page.
Export the previous video's Final Frame PNG from Library, put it into Video -> First Frame,
reselect continuity presets and describe only the next visible action.

2. ВИДЕО ПО АУДИО
------------------
Audio-driven performance / singing / dancing / music-video generation.

Inputs:
- saved master track or uploaded audio;
- selected audio fragment;
- optional visual reference;
- Characters/Locations/Misc presets.

Important controls:
- "Вклеить трек в видео": use the chosen original master-track fragment in final MP4.
- "Фоновые звуки H3": optional additional generated physical/ambient scene audio.

The master track is external driving audio, not score H3 should reinvent.
Normally:
non_diegetic_music: N/A

If H3 scene sound is off:
overall_soundscape: N/A

Do not invent lyrics.

3. ИЗОБРАЖЕНИЯ
---------------
MiniMax H3 Image workspace on the RTX2080-class secondary GPU.

Purpose:
- text-to-image;
- reference-guided still image generation;
- redraw/edit of one existing generated result.

Visible settings:
- Quality: 480p / 720p / 1080p
- Format: 1:1 / 16:9 / 9:16
- Seed

Quality + Format use the SAME backend pixel mapping as Video.
The image workflow itself uses fixed H3 Image inference settings internally; raw sampler/model controls are hidden.

References:
- selected Characters, Locations and Misc presets from the right rail are real image references;
- Character voices are irrelevant in this workspace;
- local Image reference limit is 16 images.

Image Magic Wand:
- uses the dedicated H3 Image guide;
- returns ONE still-image prompt/instruction;
- does NOT use H3 Video three fields;
- no Shot blocks;
- no timestamps;
- no audio fields;
- no invented Picture numbers.

Redraw/edit:
- only one generated result can be checked at once;
- checking it automatically switches to edit mode;
- backend makes it the edit target/Picture 1;
- prompt should preserve everything not explicitly requested to change.

Results:
- maximum 8 per user;
- newest result appears first;
- when a ninth is saved, the oldest database row and file are removed;
- button "1" sends the PNG to Video -> First Frame;
- button "2" sends the PNG to Video -> Last Frame;
- download and delete are available.

4. ПРЕСЕТЫ
----------
Right rail contains THREE tabs.

Characters:
- 1–4 appearance reference images;

- optional saved voice;
- voice may be muted for Video;
- in Images only appearance refs matter.

Locations:
- 1–4 environment references;
- saved location prompt.

Misc ("Прочее"):
- prop;
- clothing_gear;
- weapon;
- vehicle;
- creature;
- environment_feature;
- visual_trait;
- pose_action;
- style_look;
- other.

Misc presets contain 1–4 images plus category/description and are real semantic references.
