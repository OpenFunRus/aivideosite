# Библиотека и тестовая генерация MiniMax H3

## Реализовано

1. В разделе «Видео» две кнопки: обычная и тестовая генерация. Обе используют общую модалку выбора свободной GPU.
2. Тестовая модалка позволяет остановиться после любого целого шага от 1 до текущего числа проходов (8/12/16).
3. Библиотека содержит сводку RTX 3090/RTX 2080, активные задачи генерации и экспорта, готовые ролики. Отдельного экрана «Очередь» нет.
4. Активные карточки показывают анимацию, процент, этап, GPU и секундомер; обычный запуск не делает промежуточных изображений.
5. `AIVideoTestPause` перехватывает callback сэмплера, останавливается после выбранного прохода и ожидает файл `.resume` либо `.cancel`. Латент/состояние сэмплера остаются в памяти, ранее выполненные проходы не пересчитываются.
6. На тестовой паузе доступны черновое видео Tiny VAE (8 разреженных кадров) и, если генерируется звук, первые пять секунд через H3 Audio VAE. Отдельные кнопки продолжают или отменяют генерацию.
7. Таймер рендера запускается с первого фактического сообщения о проходе от ComfyUI, а не при постановке задания в очередь/загрузке модели. В Библиотеке счёт идёт по серверному времени, поэтому неверные часы браузера его не сдвигают. Готовое видео отображает эту длительность на обложке, под проигрывателем — дату начала проходов и длительность без интервала тестовой паузы.

## Развёртывание на Ubuntu

Обновлять службы только после завершения всех текущих генераций и тестовых пауз:

```bash
cd /opt/ai/aivideosite
git pull --ff-only origin main
bash scripts/setup_h3_preview.sh
bash scripts/setup_h3_test_pause.sh
sudo systemctl restart comfyui.service comfyui-secondary.service
sudo systemctl restart aivideosite.service
```

Проверка регистрации новых узлов:

```bash
for port in 8188 8189; do
  for node in AIVideoTestPause MiniMaxH3AudioPreviewCS MiniMaxH3PreviewOverride; do
    curl -fsS "http://127.0.0.1:$port/object_info/$node" >/dev/null || echo "Проблема: $port $node"
  done
done
```

## Ручная проверка

- [ ] Откройте Библиотеку: обе GPU на месте, вкладка «Очередь» исчезла; на телефоне GPU располагаются вертикально.
- [ ] Обычный запуск — выбор GPU, автоматический переход в Библиотеку, анимация/процент без Tiny VAE кадров; отмена удаляет рабочую карточку.
- [ ] Запуск теста с 8 проходами, остановка после шага 4. Появляется «Пауза», кнопка просмотра и «Продолжить», GPU остаётся занятой.
- [ ] В тестовом окне видно черновое видео; если звук включён, доступен WAV-плеер. На первых шагах речь может быть шумной.
- [ ] Нажать «Продолжить»: прогресс растёт дальше, после полного завершения появляется финальный MP4, GPU освобождается.
- [ ] Повторить остановку на шаге 1 и на максимальном шаге 8, проверяя, что проходы не дублируются.
- [ ] Отменить тест на паузе, убедиться, что ComfyUI разблокировался и GPU доступна для новой генерации.
- [ ] На готовом видео проверить время сверху справа, дату и затраченные минуты/секунды под проигрывателем.
- [ ] Проверить обе видеокарты, экспорт из «Монтажа», обновление страницы во время обычного рендера, доступ разных пользователей к своим черновикам.

## Границы текущего этапа

- Тестовая пауза **не переживает рестарт** сайта/ComfyUI. При старте сайта оставшиеся блокировки помечаются для отмены, а прерванная задача ставится заново и начинает проходы с первого шага.
- На время ожидания весь H3 сэмплер и VRAM остаются занятыми; пауза не освобождает GPU. Полный Video VAE не запускается внутри сэмплера, чтобы не вызвать OOM.
- Звуковой предпросмотр — первые пять секунд. Ранний проход может давать неразборчивый звук; промежуточное видео Tiny VAE также может быть размыто.
- Audio Preview — внешний модуль GPL-3.0. Его реальная совместимость и нагрузка на RTX 3090/2080 проверяются на сервере; локально тестировались только API, workflow wiring и логика блокировки сэмплера.
