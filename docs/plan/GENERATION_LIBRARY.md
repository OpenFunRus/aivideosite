# Генерация MiniMax H3 и Библиотека

## Что работает

1. В разделе «Видео» одна кнопка «Сгенерировать видео», выбор RTX 3090/RTX 2080 и выбор числа проходов **1, 2, 4, 8, 12, 16**.
2. Кнопка отправляет задачу и автоматически открывает Библиотеку. Отдельного экрана «Очередь» нет.
3. В Библиотеке расположены сводка обеих GPU, рабочие карточки с анимацией/процентом/этапом/таймером и готовые видео.
4. Независимо от числа проходов ComfyUI заканчивает семплирование и выполняет **полный Video VAE** (и Audio VAE, если включён звук), а затем сохраняет MP4.
5. Таймер начинается с первого фактического прохода ComfyUI и учитывает серверное время, а не часы браузера; длительность сохраняется в metadata.
6. Tiny VAE, промежуточные кадры, кнопка теста и возможность остановить/продолжить сэмплер не используются.
7. `AIVideoRunNonce` помогает повторять генерации с одним Seed без возврата закэшированного результата. При смене числа шагов видео и звук закономерно могут изменяться.

## Развёртывание на Ubuntu

Проводить после окончания текущих генераций (выполненные старые задачи остаются в Библиотеке):

```bash
cd /opt/ai/aivideosite
git pull --ff-only origin main
bash scripts/setup_h3_run_nonce.sh
sudo systemctl restart comfyui.service comfyui-secondary.service
sudo systemctl restart aivideosite.service
```

Повторная установка узла не нужна, если `AIVideoRunNonce` уже установлен на обеих ComfyUI. Для проверки:

```bash
for port in 8188 8189; do
  curl -fsS "http://127.0.0.1:$port/object_info/AIVideoRunNonce" >/dev/null || echo "Проблема: $port"
done
```

Установленные ранее сторонние плагины Tiny VAE/Audio Preview/TestPause на сервере можно не удалять — новый граф на них не ссылается.

## Ручная проверка

- [ ] В разделе Видео только кнопка генерации; доступны проходы 1/2/4/8/12/16, Seed и переключатель звука.
- [ ] При выборе 2 проходов и GPU переход в Библиотеку происходит автоматически; показывается прогресс и время со старта генерации.
- [ ] После 2 проходов появляется обычный MP4 (не размытое промежуточное Tiny VAE); при включённом звуке проверить реальное наличие аудиодорожки.
- [ ] Повторить с тем же промптом, кадрами и Seed на 12 проходах: генерация действительно запускается заново и сохраняет отдельный MP4.
- [ ] Проверить каждое значение шагов на тестовом коротком ролике, особенно 1 проход на обеих видеокартах.
- [ ] Отменить текущую генерацию и проверить исчезновение рабочей карточки.
- [ ] Проверить время над обложкой готового видео, дату старта и длительность в проигрывателе.
- [ ] Проверить обе видеокарты, экспорт из Монтажа, обновление страницы во время рендера и разделение контента по пользователям.

## Ограничения

- 1–2 прохода могут быть слишком грубыми для качественной картинки/звука. Полный декодер не компенсирует недосэмплирование.
- Повысить число шагов с 2 до 12 означает заново запустить все 12 шагов; продолжения прежних латентов нет.
- Фактическая совместимость MiniMax H3, выходной MP4/аудио и видеопамять RTX 3090/RTX 2080 проверяются на Ubuntu.
